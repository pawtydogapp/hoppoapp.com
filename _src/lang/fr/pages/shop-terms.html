Ajoutez des produits à votre panier, choisissez votre pays, saisissez un code promo si vous en avez un, et payez sur la page sécurisée de Stripe. Vous y saisissez votre nom et votre adresse de livraison. Votre commande est confirmée quand votre paiement aboutit et que Stripe vous envoie votre reçu par e-mail. Nous pouvons annuler et rembourser une commande si un produit n'est pas disponible ou si un prix a été affiché par erreur.

7. Votre droit de rétractation

Vous pouvez vous rétracter de votre commande dans les 14 jours après la réception des marchandises, sans donner de motif. Informez-nous clairement par e-mail, par exemple « Je me rétracte de ma commande numéro 1001 ». Renvoyez les marchandises dans les 14 jours après nous en avoir informés. Nous remboursons le prix et les frais de livraison standard dans les 14 jours après avoir reçu les marchandises, ou après que vous avez prouvé que vous les avez envoyées. Vous payez les frais de retour des marchandises sauf accord contraire entre nous.

Ce droit ne s'applique pas aux marchandises réalisées selon vos spécifications, ni aux marchandises scellées qui ne peuvent pas être renvoyées pour des raisons d'hygiène une fois que vous les avez ouvertes.

Vous avez droit à une réparation, à un remplacement, à une réduction du prix ou à un remboursement, selon les règles de votre pays.

9. Codes promo

Un code promo n'a aucune valeur en espèces et s'applique aux produits, pas aux marchandises déjà commandées. Vous pouvez utiliser 1 code par commande. Un code peut avoir une date de fin, une commande minimum ou un nombre d'utilisations limité. Nous pouvons retirer un code à tout moment. Un code déjà appliqué à une commande confirmée reste valable pour cette commande.
